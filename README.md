ANLEITUNG ZUR AUSFÜHRUNG DES JAVA-PROGRAMMS "ZAHLENSYSTEME_RECHNER"

====================================

Voraussetzungen:
- Java JDK Version 10 oder höher muss installiert sein.
- Prüfen Sie die Version mit:

java -version

====================================

WINDOWS:
1. Öffnen Sie die Eingabeaufforderung (CMD).
2. Navigieren Sie mit dem Befehl 'cd' zum Speicherort des Programms, z. B.:

cd C:\Users\Luca Elias Hönert\Downloads\

3. Drücken Sie Enter.
4. Führen Sie das Programm aus:

java -jar Zahlensysteme_Rechner.jar

====================================

1. Öffnen Sie das Terminal.
2. Navigieren Sie mit dem Befehl 'cd' zum Speicherort des Programms, z. B.:
